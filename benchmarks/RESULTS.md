# Benchmark results (canpii 0.1.0)

Generated by `python benchmarks/run_benchmark.py` with presidio-analyzer 2.2.366,
spaCy 3.8 (`en_core_web_sm`, `fr_core_news_sm`), Python 3.13. Synthetic template
corpus: a regression benchmark, **not** a real-world accuracy estimate. See README.

The first two tables are canpii's precision and recall per entity under Presidio's two
context matching modes. The "Stock Presidio vs Presidio + canpii" section runs the same
positive sentences through a stock Presidio `AnalyzerEngine` and reports recall only;
how a hit is counted is stated there. Things to keep in mind when reading it:

* Stock Presidio's "same type" recall is 0 by construction: it has no recognizer for
  these five entities, and it ships `CA_SIN` disabled.
* "Any type" is the generous reading for stock Presidio: the span was flagged, but as
  `PHONE_NUMBER`, `DATE_TIME`, `US_DRIVER_LICENSE`, … (last table). A redaction pipeline
  would still mask those characters; an entity filter or a policy keyed on entity type
  would not. "Full span" is the stricter variant: a partial overlap leaves part of the
  identifier in the text.
* canpii's weak spot is positives **without** context words: passport and bank numbers
  are context-only patterns, so their recall in bare sentences is 0 of 20 and 0 of 60
  ("all positive sentences" minus "sentences with context words").
* Stock Presidio is run with the same small spaCy models and its default NER label
  mapping (which ignores `ORGANIZATION`); `create_analyzer()` does not ignore
  `ORGANIZATION`, which slightly favours canpii in the "any type" column only.

Corpus: 1740 sentences (740 positive, 1000 negative), en+fr, seed=2026, threshold=0.4

## Stock Presidio vs Presidio + canpii

Recall only. Stock Presidio = `AnalyzerEngine` with its default recognizers and the same spaCy small models; canpii = `create_analyzer()`. Both run all their recognizers. A gold span is found when a prediction with score >= 0.4 overlaps it. "same type": the prediction has the gold entity type. "any type": any entity type at all. "full span": one prediction covers the whole gold span. "threshold 0": Presidio's default threshold instead.
